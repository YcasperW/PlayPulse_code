# 编码字典 · 把文本换成数字

> 用途：所有开放题、归因、选择，一律**先编码成数字再入库**。
> 文本只在"备注"列保留原文，用于回看，不参与统计。

## 1. 卡关原因编码（stuck_reason_code）

| 码 | 归因 | 修法方向 |
|---|---|---|
| 0 | 没卡住 | — |
| 1 | 资源不够 | 调产出 / 调消耗（数值问题） |
| 2 | 概率不好（脸黑） | 加保底 / 降低方差（随机性问题） |
| 3 | 没看懂规则 | 改引导 / 改 UI 提示（信息问题） |
| 4 | 操作繁琐 | 减步骤 / 加一键（交互问题） |
| 5 | 不知道要干嘛 | 改目标呈现（动机问题） |

**原始文本怎么编码**：自由回答按上表归类；一句话里出现多个原因时，取**第一个**提到的（最重要）。
无法归类的记 9，并在备注留原文。

## 2. 卡关选择编码（stuck_choice_code）

| 码 | 选择 | 含义 |
|---|---|---|
| 0 | 没卡住 | — |
| 1 | 继续等 / 继续攒 | 容忍度高，或没有更好的出口 |
| 2 | 看广告 | 广告位自然触发 |
| 3 | 付费 | 付费意愿的真实信号（**注意：内部测试只能问意愿，不能真付费**） |
| 4 | 想退出 | **最强流失信号**，等同于准流失点 |

## 3. 难度增量（difficulty_delta）

不用绝对 1–7 分（每个人锚点不同，10 个人 10 套标准），改问**相对上一关**：

> "这关比上一关难多少？"-2 容易很多 / -1 容易一点 / 0 差不多 / +1 难一点 / +2 难很多

好处：自带基线校准，跨人可比；累加后直接得到**感知难度曲线**，可与客观耗时曲线叠图找背离。

## 4. 感知掉率（perceived_drop_rate）

玩家填："你觉得下一个箱子出稀有物的概率是 ___%"（0–100 整数）。

- 与配置概率对比 → **感知偏差 = 感知 - 实际**
- 偏差 < -15pt：玩家觉得概率比实际低 → 保底没被感知到，或反馈太弱
- 偏差 > +15pt：预期被吊高，后续必失望

## 5. 流失关卡（quit_at_level）与次日回归（next_day_return）

- `quit_at_level`：**数字**。投射法问"你觉得普通新手会在第几关流失"。
- `next_day_return`：0/1。第二天**不提醒**，看他会不会自己打开。这是小样本下最接近 D1 的东西。

## 6. 文本字段的处理原则

| 原则 | 说明 |
|---|---|
| 能编码的绝不自由填 | 开放题回收率高但**不可统计**，10 份问卷做不出任何结论 |
| 编码表要提前定 | 事后看着答案编编码 = 先射箭后画靶 |
| 文本只留不删 | 放在备注列，用于解释数字异常（比如某关无效操作率突然飙高，回看备注才知道是 UI 改了位置） |
| 一个文本列配一个数字列 | 例如"最想跳过的部分"→ 关卡号（数字）+ 原因编码（数字）+ 一句话原文（文本） |
